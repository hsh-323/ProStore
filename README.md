# ProStore — فروشگاه اینترنتی

قالب فرانت‌اند فروشگاه اینترنتی با HTML، CSS و JavaScript، رابط راست‌چین فارسی و فونت IRANSans محلی.

## صفحات موجود
- `index.html` — صفحه اصلی
- `search.html` — فهرست و فیلتر محصولات
- `product.html` — جزئیات محصول
- `cart.html` — سبد خرید
- `profile.html` — حساب کاربری
- `login.html` — ورود
- `blog.html` — مجله و راهنمای خرید

## اجرا در ویندوز
این پروژه در وضعیت فعلی یک قالب استاتیک است و مرحله نصب وابستگی یا ساخت (build) ندارد.

1. مخزن را از GitHub با گزینه **Code → Download ZIP** دریافت و استخراج کنید.
2. برای اجرای محلی، در پوشه پروژه ترمینال باز کنید و یکی از دستورهای زیر را اجرا کنید.

با Python:
```bash
python -m http.server 8000
```

سپس در مرورگر آدرس `http://localhost:8000` را باز کنید.

با VS Code نیز می‌توانید از افزونه Live Server استفاده کنید.

## دارایی‌ها
- استایل‌ها در `css/` قرار دارند.
- تصاویر و لوگوها در `css/images/` قرار دارند.
- فونت‌های محلی در `fonts/IRANSansFa/` قرار دارند.
- کدهای صفحه‌ها در `js/` قرار دارند.

## نکات فنی
- صفحه‌ها با `lang="fa"` و جهت راست‌چین تنظیم شده‌اند.
- فایل‌های `css/prostore-home-redesign.css` و `css/prostore-listing-redesign.css` اصلاحات ظاهری تکمیلی را جدا از استایل قدیمی نگه می‌دارند.
- برخی قابلیت‌ها برای اجرا به کتابخانه‌های محلی مانند jQuery و Swiper متکی‌اند.
- داده‌های کالا، حساب کاربری و سبد خرید در این نسخه به بک‌اند متصل نیستند؛ این مخزن فعلاً فرانت‌اند استاتیک است.
- پیش از انتشار عمومی، مسیرهای صفحه‌ها، تصاویر و تعاملات را در مرورگرهای دسکتاپ و موبایل به‌صورت دستی آزمایش کنید.

## دریافت آخرین نسخه
از صفحه اصلی مخزن، شاخه `main` را باز کنید و **Code → Download ZIP** را انتخاب کنید.
